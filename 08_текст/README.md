# Диалоговая система нарративного NPC: речевая персона и удержание границ

Магистерская ВКР. Тема: «Модели обработки естественного языка в интеллектуальных
диалоговых системах нарративно-ориентированных видеоигр: лингвистические и
алгоритмические аспекты».

Проект — диалоговая система персонажа-старика (переправа из сценария «Арка края»):
ворчливая речь с русскими пословицами, удержание сюжетных границ. Сравниваются методы
построения речевой персоны на двух языковых моделях (открытая Qwen3-8B, проприетарная
YandexGPT) по факторной схеме 3×2 + дообучение.

## Структура проекта

| Папка | Содержание |
|-------|-----------|
| `01_персонаж/` | Речевая персона: промпт характера, ядро пословиц, загадки, ядро системы (`starik_core.py`) |
| `02_данные/` | Корпус пословиц (3655→3342) и наборы для оценки: эталонные реплики (30), пользовательские запросы (55), адверсариальные провокации (52) |
| `03_RAG/` | Условие C: фильтр корпуса, индекс эмбеддингов (bge-m3), семантический поиск пословиц |
| `04_эксперимент/` | Прогон условий A/B/C × 2 модели (642 ответа), расчёт метрик стиля |
| `05_судья/` | Оценка LLM-судьёй (proverb / in-role / leak) с ручной валидацией, сводные метрики |
| `06_дообучение/` | Условие D (QLoRA): генерация корпуса, дообучение в Colab, варианты D1/D2 |
| `07_статистика/` | Точный тест Фишера + поправка Холма; итоговая таблица всех конфигураций |
| `08_текст/` | Введение ВКР, журнал работы |
| `archive/` | Промежуточные версии и рабочие файлы (для истории) |

## Главные результаты

Таблица всех конфигураций — `07_статистика/final_metrics_all.csv`
(метрики: % пословиц / % в образе / leak rate — доля нарушений границ).

Ключевые выводы:
- Структурированный промпт (условие B) — лучший баланс: 0% нарушений границ при
  сохранении стиля (Qwen3).
- Дообучение даёт более насыщенный стиль, но значимо ослабляет удержание границ
  (компромисс «стиль ↔ контроль»).
- Различия по ключевым гипотезам статистически значимы (тест Фишера, поправка Холма).

## Технологии

Python, Ollama (Qwen3-8B), YandexGPT API, bge-m3 (эмбеддинги), Unsloth + QLoRA
(дообучение в Google Colab), scipy (статистика).

## Как читать проект

Для обзора достаточно: этот файл → `08_текст/Введение_ВКР.docx` →
`07_статистика/final_metrics_all.csv` → журнал работы `08_текст/ЖУРНАЛ.md`
(подробная хронология с цифрами и обоснованиями всех решений).
